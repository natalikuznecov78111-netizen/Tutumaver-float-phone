# Tutuma Float Phone 1.6.1（26.11.13）

本项目基于小笼包老师的 **AI Virtual Phone** 原始项目，并在 **MOMO（末末）老师的二次开发版本**基础上继续开发。

本版本对部分原有内容进行了取舍与调整，持续优化交互体验和移动端适配，整体更偏向 **Android 端的便捷操作与使用习惯**。

## 项目来源

- **原始项目 · 小笼包**：[ai-virtual-phone](https://github.com/xiaolongbao0709/ai-virtual-phone)
- **二次开发 · MOMO（末末）**：[momo.float.phone](https://github.com/jianchu-in/momo.float.phone)
- **三次开发 · Tutuma Float Phone**：基于 MOMO 二改版本继续开发与完善。

## 关于本版本

本仓库用于整理与分享三次开发成果。具体新增功能、修改内容及 App 使用方法，将在分享版功能确认后单独整理。

本项目并非从零开发；原版、二改及其他贡献者的成果归属于对应作者。发布前将核对并保留适用的开源许可证、版权声明及第三方素材授权信息。

## 当前状态

分享版源码正在进行内部验证，暂未正式发布安装包。App 详细使用说明会在功能定稿后补充。

## 1.2 更新

小红书沿用原生消息页，移除重复铃铛入口；点赞、收藏、评论、私信及新增关注可按设置显示灵动岛或横幅提醒。

## 1.4 更新

日历角色切换、应用返回手势、Chat 作息与通话、通知、本地备份、WVS 直播、提问箱卡片和小说功能更新。具体同步范围见 [同步记录](docs/同步记录-完整版034.md)。

## 1.5 更新

优化 Chat／Lysn 多图洗牌与图片展开、单图和实况显示、AI 配图偏好、泡泡交互、相册保存、聊天截图、电话短信设置，并恢复可控制提示词注入的全屏特效总开关。详细内容见 [1.5 更新记录](docs/1.5更新说明.md)。

## 1.5.1 返回交互修复

修复 Android 手势返回和页面按钮行为不一致的问题：Chat 单聊、群聊的语音与视频通话在手势返回时优先缩小为悬浮窗；Weverse Live 手势返回会显示已有退出确认，可选择后台继续或结束，不会直接跳过确认。其他分享版功能和精简范围不变。

## 1.6 更新

完善 Chat／电话通话 UI、真实视频与独立原声音量、通话及 WVS 返回手势、默认提示音、相册图片匹配、X 生图保存和提问箱日历关联。详见 [1.6 更新记录](docs/1.6更新说明.md)。

## 1.6.1 更新

恢复了chat聊天界面的头像显示圆角，已还原为原始圆形头像，可自由替换美化。为chat聊天设置新增快捷切换语音绑定功能，全局通用。不着急可以不用同步。
